## Project Status
Ostival is an active work in progress built with modern C++ and Qt. The goal is to create an open-source tool to assist with front-end digital VLSI design flows.

## Requirements
* **Qt:** 6.10.3 or higher
* **CMake:** 3.16 or higher
* **C++ Compiler:** Clang, GCC, or MSVC supporting `C++17` or later

## Building

```bash
# Clone
git clone https://github.com/ostival/ostival-gui.git
cd ostival-gui

# Configure & Build
cmake -B build -S .
cmake --build build 
```
